GitHub PR Assignee Tab Groups

GitHub Needs read access to pull requests and issues (classic: repo; fine-grained: Pull requests and Issues: Read). The token from gh auth token works. Stored only in this browser profile.

Assignee groups

Checked by GitHub API for github.com/<owner>/<repo>/pull/N and /issues/N. These take precedence over URL rules.

URL rules

First match wins, top to bottom. Same pattern syntax as Auto-Group Tabs: example.com, *.example.com, https://example.com/foo/*, chrome://*, *, or a regex like /^https:\/\/example\.com\//.
